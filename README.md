## 📌 Project Overview
The **E-Commerce Management Platform** is a robust web application built with **React and TypeScript** that enables both customers and managers to efficiently manage an electronics e-commerce store. Users can browse, purchase, and track orders, while managers can oversee inventory, manage products, and process orders. 

The platform follows **modern software engineering practices**, including **formal testing** (unit, integration, and system testing) with formal verification to ensure maximum reliability and efficiency.

## 🚀 Getting Started
### 🔧 Prerequisites
Ensure you have the following installed:
- Node.js 16+ 🟢
- npm or yarn 📦
- Docker (optional for deployment) 🐳

### 📥 Installation
Clone the repository and navigate into the project directory:
```sh
 git clone https://github.com/Andrea-1704/Ezelectronics.git
 cd ecommerce-platform
```

Install dependencies:
```sh
npm install  # or yarn install
```

### ▶️ Running the Application
Start the development server:
```sh
npm run dev  # or yarn dev
```

## 🛠️ Usage
- **Users can:**
  - Browse and search products
  - Add items to the cart and checkout
  - Track their orders
  
- **Managers can:**
  - Add, update, and remove products
  - Monitor inventory and sales
  - Manage user orders
